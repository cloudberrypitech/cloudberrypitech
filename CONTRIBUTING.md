# Contributing
To contribute or give feedback to our repository, please visit our https://forms.cloud.microsoft/r/9W6uFBHFn7[Project Feedback Page]. As your support helps us grow.

To add your software content, please search for the projects with the note `open-source` in the README file. This means that you can build the code and pull-request it to the repo and wait for the request approval.
Thank you!
